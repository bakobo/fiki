# fiki-py drops the brackets from an IPv6 literal in @authority: py/src/fiki/base.py:177 builds it from urlsplit().hostname, so https://[::1]:8443/x yields '::1:8443'. RFC 9421 section 2.2.3 takes the authority of the target URI, and RFC 3986 section 3.2.2 spells an IPv6 host as IP-literal '[::1]', so the base should read '[::1]:8443'. The js port keeps the brackets (found by the js parity worker 2026-10-07), so py and js compute different bases for an IPv6 target while both claim vectors_format 1, and no vector catches it. Fix py (keep brackets, lowercase inside them), check go/rust/java/csharp agree, and add an IPv6 case at the next vectors_format bump.
