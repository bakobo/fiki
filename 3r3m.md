# A caller's component name holding a lone surrogate (e.g. '@pa' + U+D800) is a caller error in fiki-java (per @3e7wnyvg) and UnsupportedComponent in fiki-py; js and C# unchecked. Caller input, not wire input, and no shared vector can carry a lone surrogate portably (serde_json refuses it, Go rewrites it), so this needs one rule (likely caller error, since the spec must be an RFC 8941 string) and a native test per UTF-16 port. Split out of the format-4 bundle on 2026-10-12 (this.i @646un6k8) because it changes no vector.
